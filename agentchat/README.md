# Agent Chat

MiraSpeak module. Sends what you type to an agent and plays a filler while you wait. The agent speaks the reply.

Needs MiraSpeak with module API 1.

## Install

In MiraSpeak, open **Integrations → Modules → Install from URL…** and paste:

https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/agentchat

The link sets the tag and the folder.

It asks for **network** and **filler**. A Python module runs inside MiraSpeak with the same access as the app.
