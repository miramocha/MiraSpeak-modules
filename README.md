# MiraSpeak modules

Official MiraSpeak modules. Each folder is one module. Install it from MiraSpeak with **Integrations → Modules → Install from URL…** and paste the link. The link sets the tag and the folder.

| Module | Install |
| --- | --- |
| Timer | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/timer |
| Lyrics | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/lyrics |
| EPUB | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/epub |
| Agent Chat | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/agentchat |

Timer says a phrase on a schedule. Lyrics looks up a song on [LRCLIB](https://lrclib.net). EPUB opens a local book and reads it aloud. Agent Chat sends what you type to an agent and plays a filler while you wait. The agent speaks the reply.

These modules run inside MiraSpeak with the same access as the app. A network grant is not limited to the host named in the module.
