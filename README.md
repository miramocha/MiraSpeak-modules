# MiraSpeak modules

Official MiraSpeak modules. Each folder is one module. Install it from MiraSpeak with **Integrations → Modules → Install from URL…** and paste the link. The link sets the tag and the folder.

| Module | Description | Install |
| --- | --- | --- |
| Timer | Says a phrase on a schedule. | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/timer |
| Lyrics | Looks up a song on [LRCLIB](https://lrclib.net). | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/lyrics |
| EPUB | Opens a local book and reads it aloud. | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/epub |
| Agent Chat | Sends what you type to an agent and plays a filler while you wait. The agent speaks the reply. | https://github.com/miramocha/MiraSpeak-modules/tree/v0.1.0/agentchat |
| Discord | A Discord bot plays what MiraSpeak speaks in your voice channel. Installs its own Python packages. | https://github.com/miramocha/MiraSpeak-modules/tree/v0.2.0/discord |

These modules run inside MiraSpeak with the same access as the app. A network grant is not limited to the host named in the module.
